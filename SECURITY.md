# Security policy

## Scope

humanizer-lint analyzes text locally. The CLI and library make no network requests and have no runtime dependencies. Reports about code execution, path handling, unsafe output formatting, or a vulnerable GitHub Actions workflow are in scope.

## Supported versions

Security fixes are applied to the latest released version only.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting: https://github.com/yanstd888/humanizer-lint/security/advisories/new

Do not open a public issue for a vulnerability. Include the affected version, steps to reproduce, and the impact you observed.
