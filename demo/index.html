    Eight anti-slop packs, plus universal stylometry

    Humanizer-Lint is an AI humanizer, prose linter, stylometric analyzer, burstiness checker, and deterministic local CLI text validator. It measures sentence length variation, coefficient of variation (CV ≥ 0.45), adjacent sentence rhythm delta, moving-average type-token ratio (MATTR), and zlib compression entropy while retaining private local analysis.

    FAQ

    Can this tool prove human authorship?

    No. It checks configured writing-style signals, not who wrote the text.

    Does the playground send text to a server?

    No. Analysis is client-side and the CLI has no runtime network dependency.

    Which languages are supported?

    Eight Tier 1 packs cover EN, ID, ES, MS, FR, DE, PT, and ZH. Universal stylometry supports 100+ languages.
