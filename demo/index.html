    FAQ
    Can this tool prove human authorship?
    No. It checks configured writing-style signals, not who wrote the text.
    Does the playground send text to a server?
    No. Analysis is client-side and the CLI has no runtime network dependency.
    Which languages are supported?
    Eight lexical packs cover EN, ID, ES, MS, FR, DE, PT, and ZH. Universal rhythm diagnostics support 100+ languages.
